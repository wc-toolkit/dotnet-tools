Generate a shared Blazor architecture from a Custom Elements Manifest: shared component and input base classes, named and default slots, typed standard and custom events, and generated enums and records for inline object shapes on attributes, method parameters, and method returns. Add configurable form value members, element validity helpers, CEM parity validation, and generated-project verification in CI and release. Respect the CEM `privacy` property so private and protected members are excluded from generated wrappers, Tag Helpers, and parity checks. Generated inputs supply a default `ValueExpression` so they render when used with `Value` alone, without `bind-Value`. Named slots render only when content is supplied, and their wrapper element is configurable through `slotWrapperTag`. Generate `boolean` attributes whose manifest default is `true` as a tri-state `bool?` with an explicit off value, configurable through `booleanOffValue`, so they can be turned off instead of silently falling back to the element's own default. Format numeric attribute values with the invariant culture so hosts running under a comma-decimal locale do not emit unparseable values.
